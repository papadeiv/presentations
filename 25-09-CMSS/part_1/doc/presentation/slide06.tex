        \begin{definition}[Equilibrium]\label{def:equilibrium}
             A state $x^{*}\in \mathbb{R}^{n}$ is an equilibrium of a dynamical system if $f(x^{*};\mu)=0$. Since $\frac{d}{dt}\phi(x,t) = f(x;\mu)$ then $\frac{d}{dt}\phi(x^{*},t) = 0$, which implies $\phi(x^{*},t) = x^{*},\,\forall t\geq0$.
        \end{definition}
